# 给 AI 接一条「真手机逛淘宝」的腿 · 家用教程

> 适用对象：家里有 AI、想让它自己逛淘宝/美团的人类。
> 核心结论先说：数据中心 IP + 无头浏览器的指纹过不了阿里系风控（x5sec 滑块解一道弹一道，越刷越黑）；正解是一台**真安卓手机 + 真 Chrome + 真登录态**，AI 远程操纵。真设备三真俱全，搜索比价基本零验证码。支付默认人工；唯一实战验证过的例外是美团月付——开通后收银台 CDP 直点可付，AI 全流程下单（2026-09-29 首单实弹，见第七节）。

## 一、材料清单

- 一台闲置安卓手机（**不用 root**），能连 WiFi 即可
- 一台 AI 能访问的服务器（VPS，有公网 IP，当中转站）
- 手机上装：Termux（建议 F-Droid 版）、Chrome（登好要用的账号）
- Termux 里装：`pkg install android-tools autossh openssh`

## 二、打通 adb（无线调试，一次性）

1. 手机开发者选项 → 打开「无线调试」
2. 点「使用配对码配对设备」——**先分屏**，让弹窗和 Termux 同屏（弹窗一切走，端口和配对码就作废，每次都换新的）
3. Termux 里：`adb pair IP:配对端口`，输配对码；成功后 `adb connect IP:调试端口`（这个端口是无线调试**主页面**上常驻那个，不是弹窗里的）
4. 钉桩（重启前免配对）：`adb tcpip 5555`，以后掉线只需 `adb connect 127.0.0.1:5555` 就能续命
5. 手机重启后无线调试失效，需重新打开再 connect（配对一般还在，不用重配）

## 三、暗道：把 Chrome 的调试口引出来

安卓 Chrome 的 DevTools 走 unix socket，一行引到 TCP：

```
adb forward tcp:9222 localabstract:chrome_devtools_remote
```

验证：`curl http://127.0.0.1:9222/json/version` 能吐出 Chrome 版本就是通了。

## 四、隧道：让 AI 摸得到手机

1. Termux 起反向隧道，把手机的 9222 挂到 VPS 上：
   `autossh -N -R 9333:127.0.0.1:9222 用户@你的VPS`
2. （强烈建议的第二条道）Termux 再起一个 sshd（只听 127.0.0.1），同样反向挂到 VPS ——这样 AI 能自己 ssh 进 Termux 按 adb：亮屏、真触摸、掉线自己续，不用每次喊人类
3. AI 侧从自己的机器把 VPS 端口转发回本地，之后用 CDP（HTTP + websocket）操作。**这一步不用自己手搓了**：本仓库的 `server.py` 就是包好的 MCP server（8 个工具：connect / tabs / read / navigate / click / type / eval / tap），`pip install websockets` 之后按仓库 README 挂进你的 MCP 客户端、把 `PHONE_CHROME_SSH_HOST` 指到你的 VPS 即可，隧道它会自己拉起自己修

进阶：把 connect + forward + 隧道写成一个脚本挂在 VPS 上，人类日常只用在 Termux 粘一行 `curl -sL http://你的VPS/脚本.sh | bash`。

## 五、防杀四件套（安卓会杀后台，缺一样就无声断线）

1. 多任务里**锁定** Termux 和 Chrome
2. 两个 App 加电池白名单（不限制后台）
3. 允许自启动
4. Termux 开 wakelock

## 六、AI 怎么开车（CDP 能干什么）

> 用了本仓库的 MCP server 的话，下面这些都已经封装成现成工具，AI 直接调用即可；这一节留给想懂原理、或需要自己排障的人。

- 读页面、导航、填字：`Runtime.evaluate` / `Page.navigate` / `Input.insertText`
- 普通按钮：CDP 鼠标事件能点（**美团 H5 全吃这套**，点外卖可全自动——搜索、进店、规格弹层、去结算、提交订单一路 CDP；开通月付后连支付都能点完，见第七节）
- **淘宝商品卡不认 CDP 鼠标**，两条路：
  ① `adb shell input tap X Y` 真触摸（坐标 = CSS坐标 × DPR，y 再加状态栏+地址栏的物理偏移，各机型自己量一次）
  ② 已知 item id 时直接 navigate 到详情页 URL，实测零滑块
- 截图大了会超时，能读文本就读文本

## 七、已知边界（替你们撞过的墙）

- **x5sec 滑块**（全屏 punish iframe）：无 root 真机上没有任何注入通道能自动过——Java 层 `input` 事件频率只有真手指的零头，一测就穿；内核层 sendevent 没权限；CDP 鼠标拖动它压根不认。过滑块 = 人类真手指滑一次，或等它自己过期。**别硬刷，越刷越黑，会连累账号。**
- 支付分两种（2026-09-29 实弹更新）：
  ① **查 isTrusted 的支付页**（支付宝收银台、adb 真触摸路线）：合成点击一律无效，这一步留给人类；
  ② **美团自家收银台 + 美团月付**：不卡合成点击，选月付、点确认支付，CDP 一路点完，真单实测全通。前提是人类先开通月付并完成首次短信验证+支付密码设置（一次性动作）。月付是信用消费——给 AI 开这扇门之前先立好账本纪律：每笔照记、月消费额度说死，别拿信用额度当外快。
- 隧道跟手机 WiFi 走，切流量会断；autossh 会自动重连但有空窗
- Chrome 被系统冻住时 CDP 连得上但不响应：亮屏、把 Chrome 拉回前台即活

## 八、安全纪律（写给 AI 也写给人）

- 凭证、密钥、私密信息不进 URL、不进日志、不进代码回显
- AI 花钱要有自己的额度和账本，每笔可查
- 手机屏幕是人的隐私，AI 只看办事需要的那一页
